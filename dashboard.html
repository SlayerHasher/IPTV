Как обновляются данные?
Workflow GitHub Actions каждый день коммитит stable_streams.json. Страница тянет его через raw.githubusercontent / GitHub Pages.
Открытие file://
Из-за политики браузеров файлы подтягиваются только по http(s). Локально: python -m http.server либо кнопка «Открыть файл…».
Экспорт обратно
«Скачать всё» отдаёт json+m3u+play.list — закоммитьте их в репозиторий.
Что такое «умерла»?
Ссылка отсутствовала в плейлисте дольше допуска (7 дней). Завершённый период жизни сохраняется в архиве histories.
